# Agent Note: WorkBuddy on dsh 0.2.1

Status: implemented

English | [中文](2026-10-20-workbuddy-0.2.1-migration.zh.md)

## Problem

The WorkBuddy surface was built on dsh 0.1.5: a directory-scanned `agent-presets` roster, `agentPresetLaunch` on the browser, and client slots that still accepted `select`. dsh 0.2.1 replaces that roster with `agent-preset-registry`, moves preset declarations into bundle patch files, changes the browser session entry to `uiWorkspace.startSession(..., { agentPreset })`, and tightens the Tool call and turn-tail node shapes. The 0.1.5 branch cannot load the 0.4.x Skin Center because the newer package waits for `configForms`, which 0.1.5 does not provide.

## Decision

The fork now branches from `origin/master` at `0.2.1-rc.2`. The custom capabilities are carried as ordinary packages beside the upstream ones:

- `packages/client/ui-workbuddy-mode`, `ui-workbuddy-scenarios`, and `ui-workbuddy-shell` keep the Ask/Plan/Craft control, the Office/Code/Design scenario dock, and the capability navigation.
- `packages/finance/finance-local`, `packages/video/video-local`, and `packages/video/xhs-local` keep the host capabilities.
- `packages/client/ui-finance-view`, `ui-video-view`, and `ui-xhs-view` keep the dedicated result cards.
- `packages/bundle/web-app/presets/{finance,video,xiaohongshu}.patch.yml` declare the three presets through `@deepseek-ai/dsh-agent-preset`.
- `packages/bundle/web-app/cordis.patch.yml` mounts the host rows, the WorkBuddy client rows, and the three cards. The scenario pick now calls `ctx.uiWorkspace.startSession(undefined, { clearPreviousDraft: false, agentPreset })`; the old `agentPresetLaunch` dependency is gone.

The finance turn-tail seat now receives `PropsRuntime<'conversation.chat.turnTail'>` and reads `turn.turn` directly. The permission projection is `PermissionSelection` (current value only), and the renamed Medium icon primitives replace the old numbered exports.

## Verification

- `pnpm install --frozen-lockfile`
- `pnpm run build` — all nine gates pass (native, host compiler/bundle/aggregate, desktop, client compiler/bundle/aggregate, web build)
- `pnpm exec vitest run` for `xhs-local`, `ui-xhs-view`, and `ui-workbuddy-scenarios`
- Booted the Web profile on 0.2.1 and used Playwright to verify: Island Life skin is active through Skin Center 0.4.7, WorkBuddy navigation is present, and the Finance, Video, and Xiaohongshu scenario chips each start their named preset with no console errors.

## Limitations

- The Xiaohongshu flow has been verified through session creation and package mounting; one real video post still needs an end-to-end render and manual publication.
- The migrated packages keep their existing tests and fixtures. Upstream 0.2.1 owns the generated remote/snapshot surfaces; this fork regenerates them through the normal build rather than carrying 0.1.5 snapshots.
